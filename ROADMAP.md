# Roadmap

- **Phase 0 — environment:** initial audit completed; Android toolchain missing; custom headless Godot built and tested as recorded in the test report.
- **Foundation — in progress:** basic spherical movement, cube-face prop partition, discovery map, three activated travel points, two contracts, limited gathering/crafting/equipment, F–D promotion checks, save and UI source. Editor import and initial headless tests passed; a graphical interactive playtest and broader stabilization remain.
- **Before calling this MVP:** real terrain and collision, production globe streaming/LOD, camera/controls, ten monster types and boss, real quest content, additional ranks and actual promotion trials, general inventory/equipment/crafting, city/village/forest/dungeon, NPC simulation, sound, proper UI, persistence and Android device tests.
- **Later planned:** six continents; F–S guild progression; dungeons/towers; skill trees and schools; equipment, crafting, economy, animals, weather and seasonal systems; events, settlements, factions and offline simulation; large-world streaming and performance optimization. Production content, asset integration and QA are substantial multi-stage work.
- **Release:** reproducible Android templates/SDK setup, signed AAB/APK, device compatibility and performance testing; no release artifact exists.

Do not treat a planned item as implemented or a source-level implementation as tested until evidence is recorded.
